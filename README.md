# UniEdTrack – Student Grade Tracking System

A web application that replaces manual, spreadsheet-based grade management at **Colombo International University (CIU)**. It automates GPA calculation, publishes marks to students in real time, and gives coordinators and administrators the reports they need.

---

## Technologies

| Layer | Technology |
|---|---|
| Frontend | React 18, React Router, Recharts, Vite |
| Backend | Node.js, Express |
| Database | MongoDB with Mongoose |
| Authentication | JSON Web Tokens (JWT), bcrypt password hashing |
| File handling | Multer (uploads), csv-parse (CSV), PDFKit (PDF reports) |
| Email | Nodemailer (Gmail SMTP) |
| Security | Helmet, CORS, rate limiting on login |
| Tooling | Git, GitHub, VS Code, Figma (UI prototypes) |
